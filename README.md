# c-pointer-puzzles

C pointer puzzles and memory layout challenges designed for systems programming enthusiasts.

⚠️ The Golden Rule:
**Solve these manually on paper without running the code!** Do not rely on compilers or debuggers. Trace the memory, pointer decay, and stack frames by hand to test your true understanding.

🚀 How to Validate (After Solving):
Once you have worked it out on paper, clone the repository and compile your prediction using GCC to see if you were right.
